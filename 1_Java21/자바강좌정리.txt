1. 기본형 
	
	 수치형 - 정수형: byte ( 1byte)
			        short (2byte)
					int  (4byte)- 기본 
					long (8byte)
			 ==> 표현: 10진수,2진수,8진수,16진수 모두 가능 
				    ex. 100 
			 
	       - 실수형: float (4byte)
		            double (8byte) - 기본 
			 ==> 표현: 소수점, 지수표현 모두 가능 
			      ex. 3.14 ( 기본인  double로 처리됨 )
  			          3.14F, 3.14f ( float 로 처리됨 )
					  3.14, 3.14D, 3.14d (double로 처리됨 )
					  
	 논리형:  boolean ( 1byte ) 
         ==> 표현식:	 true/false
		 
	 문자형:  char ( 2byte )
         ==> 표현식: '남', '여', 'A'
         ==> escape 문자 ( 특정 기능 의미)
			  '\n' : 개행(새로운 줄 생성 )
			  '\t' : 키보드 탭 클릭 효과
			  '\"' : " 효과
			  '\'' : ' 효과
			  '\\' : \ 효과
		 
		==> 문자열은 기본형에 포함안됨 (****************)
		    표현식: "hello", "홍길동"
			문자열은 참조형 데이터임. ( String 클래스가 처리)

논리연산자

논리값  && 논리값 : 그리고 해석 ( and 연산자 )
논리값  || 논리값 : 또는 해석  ( or 연산자 )
 !논리값         : 반대 해석  ( not 연산자 )
 

 and 논리식
 
 true && true:  true
 true && false: false
 false && true: false
 false && false: false
 
 
 
 or 논리식
 
 true || true:  true
 true || false: true
 false || true: true
 false || false: false
 
 not 논리식 
 !true: false
 !false: true
  
------------------------------
증감연산자(증가연산자: ++, 감소연산자: -- )

1)전치
  int n = 10;
  ++n;
  s.o.p(n) // 11
  
  //다른연산자와 같이 사용할 때
  int n2 = ++n; //전치 ( 먼저 증가하고 나중에 할당 )
  s.o.p(n2+" " + n) // 12  11

2)후치
  int n = 10;
  n++;
  s.o.p(n) //11

  //다른연산자와 같이 사용할 때
  int n2 = n++; //후치 ( 먼저  할당하고 나중에 증가 )
  s.o.p(n2+" " + n) // 11  11
