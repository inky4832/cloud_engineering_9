논리연산자

논리값  && 논리값 : 그리고 해석 ( and 연산자 )
논리값  || 논리값 : 또는 해석  ( or 연산자 )
 !논리값         : 반대 해석  ( not 연산자 )
 

 and 논리식
 
 true && true:  true
 true && false: false
 false && true: false
 false && false: false
 
 
 
 or 논리식
 
 true || true:  true
 true || false: true
 false || true: true
 false || false: false
 
 not 논리식 
 !true: false
 !false: true

증감연산자(증가연산자: ++, 감소연산자: -- )

1)전치
  int n = 10;
  ++n;
  s.o.p(n) // 11
  
  //다른연산자와 같이 사용할 때
  int n2 = ++n; //전치 ( 먼저 증가하고 나중에 할당 )
  s.o.p(n2+" " + n) // 12  12

2)후치
  int n = 10;
  n++;
  s.o.p(n) //11

  //다른연산자와 같이 사용할 때
  int n2 = n++; //후치 ( 먼저  할당하고 나중에 증가 )
  s.o.p(n2+" " + n) // 11  12

 for문 ( 용도: 반복횟수가 예측가능한 경우)
  문법: 
    
   for(시작값; 조건식; 증감연산자){

  while문 ( 용도: 반복횟수가 예측이 힘들때 또는 무한루프)
   문법:
   
      시작값;
      ...	  
      while(조건식){
	    ...

		...
	  }
   ex.
        int n = 1;
		 while(n < 6){
	    System.out.println("hello");
	    ++n;
	  }

	    ...

       int n = 1;
	   do{
	    System.out.println("hello");

생성자(constructor)

 용도: 	 인스턴스 변수 초기화
 
 문법: 
 
      public 클래스명( [변수, 변수2, ...]){ // 변수를 파라미터(parameter)라고 부름. 로컬변수에 해당.
	  
	  }
	 
	 ex. 
	    public Cat(){} <===    new Cat();
							    new Cat(10); // 갯수 불일치
		public Cat(String n){} <== new Cat("야옹이");
		                           new Cat(10); // 타입 불일치
		public Cat(String n, int a){} <== new Cat("야옹이", 2);
		..                               new Cat(2,"야옹이"); //순서 불일치
	 
 특징:
    반드시 호출해야 된다.
	new 클래스명()형식
	new 클래스명(값, 값,.. )형식  // 값을 인자(argument)라고 부름. 생성자의 파라미터와 매핑됨.
	
	반드시 파라미터(변수)와 인자(값)가 일치해야 된다.(************)

문법: 

   //생성자	
   public Cat(String n){}

   //메서드
   public 리턴타입 메서드명([변수,...]){
       ..
	   [return 값];
   }
   
특징:
  -반드시 호출해야 됨.
   => 호출방법:
		Cat c  = new Cat(); //객체생성 먼저 
		c.메서드([값,..]);
   ==> 파라미터와 인자(argument)는 반드시 일치해야 됨( 타입,순서,갯수 )     
  -호출해서 메서드가 작업후에는 반드시 호출한 곳으로 돌아온다.( 리턴(return)한다고 부름)
  - return 할때 값과 리턴타입 은 반드시 일치해야 됨.(return 값이 없는 경우에는 void 로 지정함)

4가지 형식
1) 파라미터없고 리턴값 없음.

	 public class Test{
		 public void method(){
		   ...
		 }
	 }
	 
	사용: 
	   Test t = new Test();
	   t.method();
	   System.out.println("End");
	 

2) 파라미터있고 리턴값 없음.
     public class Test{
		//오버로딩 메서드 가능
	     public void method(String n, int n2){
		    ...
		 }
		 
	     public void method(String n){
		    ...
		 }
		 
		 public void method(int n){
		    ...
		 }
	 }
	  사용: 
	   Test t = new Test();
	   t.method(10);
	   t.method("홍길동");
	   t.method("홍길동",10);
	   System.out.println("End");
	 
3) 파라미터없고 리턴값 있음.

      public class Test{
	  
		 public int method(){ // float,double 가능
			...
			return 100;
		 }
		 public String method2(){ 
			...
			return "홍길동";
		 }
		 
	 }
	   사용: 
	   Test t = new Test();
	   int num = t.method();
	   String s= t.method2();
	   System.out.println("End");
	 
	 
4) 파라미터있고 리턴값 있음.

      public class Test{
		 public int method(int n, int n2){
		 
			 ...
			 return n+n2;
		 }
	 }
	 
	  사용: 
	   Test t = new Test();
	   int num = t.method(10,20);

    public class Test{
	
		 public int method(int n, int n2){  // 메서드 ( 멤버 메서드, 인스턴스 메서드) 
		 
			 ...
			 return n+n2;
		 }
		 
		 public static void method2(String n){ //static 메서드, 객체생성 필요없음,클래스명.메서드 형식으로 사용.
		    ...
		 }
	 }
	 
	  사용: 
	  
	   Test.method2("홍길동");  //  Math.abs()
	  
	   Test t = new Test();
	   int num = t.method(10,20);
	   
2) 같은 클래스에서 메서드 호출할 때 

    public class Test{
	
		 public void method(){
		   ...
		 }
		 
		 public void method2(){
		   //같은 클래스내의 메서드 호출방법 
		   this.method(); //내부에서 호출
		   method(); // this 생략 가능(일반적인 방법)
		 }
	 }
	 
	 사용: 
	   Test t = new Test();
	   t.method(); // 외부에서 호출
	   System.out.println("End");

Call by value  vs Call by value Reference

개념: 메서드 호출시, 전달되는 인자(값,argument)가 기본형 또는 참조형에 따라서 
    전달받은 메서드에서 처리방식이 달라짐을 의미.
	
  가. Call by value
	 - 메서드에 전달되는 값이 기본형  
	
	  public class Test{
	
		 public void method(int n2){
		    n2 = 20;
		 }
	  }
	  
	  사용:
	     
	     Test t = new Test();
		 int n = 10;
		 System.out.println(n); //10
	     t.method(n); //기본형 
		 System.out.println(n); // 10
  
  
  나. Call by value Reference
     - 메서드에 전달되는 값이 참조형 
	 
	 	 public class Test{
	
		 public void method(int [] n2){
		    n2[0] = 20;
		 }
	  }
	  
	  사용:
	     
	     Test t = new Test();
		 int [] n = {10,20,30}
		 System.out.println(Arrays.toString(n); // [10,20,30]
	     t.method(n); // 참조형 
         System.out.println(Arrays.toString(n); // [20,20,30]

 static 키워드
 
 개념: 객체생성과 무관한 특징으로 프로그램 실행시 적용되는 기술임.
 
 
					        객체생성 기준(new) 
		전                                  후 				 
	 (static)                             (instance, 인스턴스)
	 적용대상:                               적용대상:
	 -변수(클래스변수,static변수)               - 생성자 
	 -메서드(static메서드)                     - 변수(인스턴스변수, 멤버변수)
	 -클래스(중첩클래스)                        - 메서드(멤버메서드, 인스턴스 메서드)
	 
	특징:                                   특징:
	-프로그램이 실행시 생성됨.                 -객체생성후 생성됨
	-단 한번만 생성됨.                        -new 할때마다 매번 생성 	
	- 인스턴스변수,인스턴스메서드,this 사용 불가  - this 사용 가능  
	- method area 메모리에 저장                - heap 메모리에 저장  
											 - static 요소 사용 가능 \\
	- 프로그램 종료시 제거됨 				    - 객체소멸시 제거됨		
	- 반드시 클래스명.멤버  형식 사용 
									
 용도:
   static 변수: 누적용 ( 단한번 생성 + 오래 유지 가능 )
   static 메서드: 객체 생성없이 메서드 사용 ( 편리함 )
               ex.  Math.abs,  Integer.parseInt,
			   
   static 클래스(중첩클래스)
     ex.
	    class Outer{
			//변수
			//메서드
			//생성자 
			
			
			class Inner{ // 중첩클래스 
			
			
			}
		 static class Inner2{ // 중첩클래스 
			
			
			}
		
		}
