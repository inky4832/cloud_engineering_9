 변경사항 비교
#############

1. 변경사항 비교

   실습:
      $ mkdir git_diff
      $ cd git_diff
      $ git init   #.git 폴더 생성
      $ touch hello.txt
      $ echo "hello" >> hello.txt
      $ git add hello.txt
      $ git commit -m "first commit"

      # 작업디렉터리 수정
      $ echo "hello2" >> hello.txt

      # 작업디렉터리와 저장소비교
      $ git diff

      # 스테이지와 저장소 비교
      $ git add hello.txt
      $ git diff --staged
      $ git commit -m "second commit"

      # 해시값 비교
      $ git log --oneline
      $ git diff b3ff9e5 5d57cb4 

     # HEAD 비교
      $ git diff  HEAD^  HEAD

############################
 작업 되돌리기1 - git Restore
###########################

1. git restore 실습

실습:
 $ mkdir git_restore
$ cd git_restore
$ git init
$ touch hello.txt   ( 반드시 tracked 파일이어야  revert가 가능 )
$ echo "hello" >> hello.txt
$ git add hello.txt
$ git commit -m 'first commit’
$ git status

$ 파일 수정만 ( add 안함 )
$ git restore hello.txt  (작업트리 수정사항 되돌리기 )
$ git status
--------------------------------------------------------------------------
2. git restore --staged 실습

$ touch a.txt b.txt  c.txt

$ echo "hello" >> a.txt
$ echo "hello" >> b.txt
$ echo "hello" >> c.txt

$ git add .      (  commit  안함  )
$ git status     
$ git restore --staged c.txt ( git add 취소하기 )
$ git status     (c.txt 파일은 더 이상 추적되지 않음)

 ############################
 작업 되돌리기3 - git revert
###########################

    실습:
 
     $ mkdir git_revert
     $ cd git_revert
     $ git init
     $ touch hello.txt
     $ echo "hello" >> hello.txt
     $ git add hello.txt
     $ git commit -m "hello commit"
     $ echo "hello2" >> hello.txt
     $ git commit -am "hello2 commit"
     $ echo "hello3" >> hello.txt
     $ git commit -am "hello3 commit"
     $ git log --oneline
       66fd4c1 (HEAD -> main) hello3 commit
       322bcb4 hello2 commit
       b524bf8 hello commit
     $ git status

     $ git revert 322bcb4    # hello2 commit으로 작업 되돌리기
     # 충돌발생 hello.txt 문서 수정

     $ git add .                     # git add 선택하면 hello.txt 유지
     $ git revert --continue .    # vsc 열림. 커밋 메시지 작성하고 파일저장.

     $ git status
     $ git log --oneline

##############
브랜치
#############

   실습:
     $ mkdir git_branch
     $ cd git_branch
     $ git init
     $ touch hello.txt
     $ echo "hello" >> hello.txt
     $ git add .
     $ git commit -m "hello commit"
     $ echo "hello2" >> hello.txt
     $ git commit -am "hello2 commit"
     $ git log --oneline
     $ git branch          # 브랜치 목록


     $ git branch hotfix   # hotfix 이름의 새로운 브랜치 생성
	
     # main 브랜치에서 hotfix로 변경
     $ git switch hotfix
        git checkout hotfix

     # hotfix 브랜치에서 hello.txt 파일 변경
     $ echo "hello3 hotfix" >> hello.txt
     $ git commit -am "hello3 hotfix commit"

     $ git log --oneline

     # main 기준으로 hotfix 차이점 출력
     $ git log main..hotfix


     # main에서 작업. main에 브랜치변경작업을 병합
     $ git switch main 
     $ git merge  hotfix
     $ git branch -D hotfix  <== 병합후에는 hotfix 브랜치 삭제

##############
브랜치 병합
#############
3. 병합 종류

 1) Fast-forward 병합

      실습:
        $ mkdir git_merge
        $ cd git_merge
	$ git init
       
       #main작업
        $ touch hello.txt
	$ echo "hello" >> hello.txt
	$ git add .
	$ git commit -m "hello commit" 
	$ git branch hotfix
	$ git switch hotfix

       #hotfix작업
	 $ echo "hello2" >> hello.txt
	 $ git commit -am "hello2 commit" 
	 $ git switch main
	  
       #main작업
         $ git merge hotfix  # Fast-forward 메시지 확인
		
 ----------------------------------------------------------------------------------
  2) 병합커밋
    
    # 현재는 main과 hotfix간의 버전이 똑같음.
     실습:
       #main작업
        $ touch world.txt
	$ git add .
	$ git commit -m "world commit"
	$ git switch hotfix

      #hotfix작업
	 $ touch happy.txt
         $ git add .
  	 $ git commit -m "happy commit"
	 $ git switch main

       #main작업
         $ git merge hotfix   # 커밋해야되기 때문에 VSC 오픈되고 커밋메시지 작성후 close하면 병합커밋이 완료됨
	   Merge made by the 'ort' strategy.

 ----------------------------------------------------------------------------------

  3) 병합충돌

       # 현재는 main과 hotfix의 hello.txt 파일내용이 동일하다.
      
      실습:

      #main작업
	$ echo "hello main" >> hello.txt
	$ git add .
	$ git commit -m "main commit" 
        $ cat hello.txt
	$ git switch hotfix  
       
      #hotfix작업
	$ echo "hello hotfix" >> hello.txt
	$ git commit -am "hotfix commit"
	$ git switch main

      # main 에서 hotfix 병합
 	$ git merge hotfix       # 충돌발생, VCS열고 충돌직접 해결(코드수정)
	                                  코드수정이 되었기 때문에 커밋해야 됨.

        $ git commit -am "final commit"
	
        $ git branch -D hotfix  <== 병합후에는 hotfix 브랜치 삭제
