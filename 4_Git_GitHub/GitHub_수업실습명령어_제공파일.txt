################################
  로컬저장소 hotfix 브랜치를 원격 저장소에 올리기  
################################

1. hotfix 브랜치 생성 및 커밋하기

$ git branch hotfix
$ git switch hotfix
$ git branch
$ echo "hello3 hotfix" >> hello.txt
$ cat hello.txt
  hello1
  hello2 
  hello3 hotfix
$ git commit ?am “hello3 hotfix commit”

#원격 저장소 연결 및 확인
$ git remote add origin https://github.com/inky4832/study.git
$ git remote -v

2. hotfix 브랜치를 원격 저장소에 push

#hotfix 브랜치 push 하기
$ git push origin hotfix


3. 원격 저장소에서 push 확인하기

4.  로컬에서 커밋 정보보기
$ git log --oneline

################################
원격 저장소의 main 브랜치를 
로컬 저장소로 가져와서 병합하기
################################

 1.  fetch + merge

   # 현재 로컬 저장소 main 커밋 상태 확인
   $ git log --oneline
   $ cat hello.txt

    # 현재 원격 저장소 main 커밋 상태 확인
   $ git log --oneline origin/main
    
   $ git fetch oring                          # 원격의 최신 정보를 로컬로 가져와서 반영 (  merge 안됨 )
   $ git log --oneline origin/main      # 로컬에 반영된 원격 최신정보 출력

   # 로컬 저장소와 원격 저장소 병합
   $ git merge origin/main                 

--------------------------------------------------------------------------

  2. pull (fetch + merge)

   $ git pull  origin  main
